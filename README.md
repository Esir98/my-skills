# my-skills

个人 AI Skills、脚本与可复用工作流集合，持续整理和更新。

## 目录

```text
skills/
  <skill-name>/
    SKILL.md        # 技能说明与使用步骤
    scripts/        # 按需添加脚本
    references/     # 按需添加参考资料
    assets/         # 按需添加模板或其他资源
```

## 添加 Skill

1. 在 `skills/` 下新建以小写字母和连字符命名的目录，例如 `my-tool`。
2. 放入 `SKILL.md`，说明用途、适用场景和操作步骤。
3. 根据需要加入脚本、参考资料或模板，并在说明中使用相对路径引用。
4. 提交到仓库；可以在下方索引中添加入口。
